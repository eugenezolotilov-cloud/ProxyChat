# 🔮 ProxyChat

**Легковесный, стильный и полностью автономный ИИ-клиент в одном файле.**

ProxyChat — это элегантный веб-клиент для удобной работы с передовыми языковыми моделями (OpenAI, Anthropic, Google Gemini) через единый API-шлюз или кастомные эндпоинты. Проект создан с упором на эстетику и минимализм: всё приложение умещается в одном файле `index.html` и работает без бэкенда или сложных сборок.

### ✨ Главные особенности
* **Архитектура одного файла:** Никаких `npm install` или настройки серверов. Просто скачайте и откройте в браузере.
* **Умный роутинг провайдеров:** Нативная "под капотом" поддержка специфичных форматов API для `gpt-5.6-terra`, `claude-opus-5` и `gemini-3.5-flash-lite`.
* **Liquid Glass UI:** Премиальный дизайн интерфейса с плавными анимациями. Поддерживает переключение между Тёмной (Dark Liquid Glass) и Светлой (Light Frosted Glass) темами.
* **PWA Ready:** Поддержка установки как полноценного приложения на рабочий стол, Android (через WebAPK) и iOS.
* **Продвинутый рендеринг:** Полноценная поддержка Markdown, подсветка синтаксиса кода (Highlight.js) и рендеринг математических формул (KaTeX).
* **Стриминг ответов (SSE):** Быстрый и плавный вывод текста в реальном времени.
* **Поддержка изображений:** Отправка визуального контекста прямо в чат для мультимодальных моделей.

### 🚀 Быстрый старт
1. Клонируйте репозиторий: `git clone https://github.com/your-username/ProxyChat.git`
2. Убедитесь, что файлы `index.html`, `manifest.json` и `icon.png` находятся в одной папке.
3. Откройте `index.html` в любом современном браузере.
4. Введите свой API-ключ в настройках и начните общение!

# 🔮 ProxyChat

**A lightweight, beautifully designed, single-file AI client.**

ProxyChat is an elegant web client designed for seamless interaction with cutting-edge language models (OpenAI, Anthropic, Google Gemini) via proxy APIs or custom endpoints. Built with aesthetics and minimalism in mind, the entire application lives within a single `index.html` file, requiring no backend or complex build processes.

### ✨ Key Features
* **Single-File Architecture:** No `npm install`, no server setup. Just download and open it in your browser.
* **Smart Provider Routing:** Native under-the-hood support for the specific API formats of `gpt-5.6-terra`, `claude-opus-5`, and `gemini-3.5-flash-lite`.
* **Liquid Glass UI:** A premium, heavily animated user interface. Features seamless toggling between Dark (Liquid Glass) and Light (Frosted Glass) themes.
* **PWA Ready:** Installable as a standalone native app on Windows, macOS, Android (via WebAPK), and iOS.
* **Rich Text Rendering:** Full support for Markdown, syntax highlighting for code blocks (Highlight.js), and complex math formulas (KaTeX).
* **Real-time Streaming (SSE):** Fast, typewriter-like response streaming.
* **Vision Support:** Easily upload and attach images for multi-modal AI interactions.

### 🚀 Quick Start
1. Clone the repository: `git clone https://github.com/your-username/ProxyChat.git`
2. Ensure `index.html`, `manifest.json`, and `icon.png` are in the same directory.
3. Open `index.html` in any modern web browser.
4. Enter your API key in the settings panel and start chatting!
